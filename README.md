# SURJEET_KAUR_PORTFOLIO
MY PORTFOLIO(WITH FLEX AND GRID LAYOUT)

# My Portfolio:
Welcome to my portfolio website, showcasing my skills and experience as a web developer and designer.

# Features:
Responsive design using Bootstrap 5
Interactive navigation menu with animations
Typed.js animation on the home banner section
About me section with a brief introduction and social media links
Skill section with progress bars and icons
Resume section with education, certifications, and work experience
Project section with a carousel showcasing multiple projects
Contact section with a form and address information
Footer with copyright information and designer credits

# Technologies Used:
HTML5
CSS3
Bootstrap 5
JavaScript
Typed.js
Font Awesome icons
Google Fonts (Roboto,Open Sans and Raleway)

# Getting Started:
To view the website, simply open the index.html file in a web browser or select option to run on live Server(Extension) in Visual Studio Code
